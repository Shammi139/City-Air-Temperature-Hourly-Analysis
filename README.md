# City Air Temperature Hourly Analysis

## Project Overview
This project analyzes hourly air temperature data of a city using Python.

## Objective
- Study hourly temperature variation
- Visualize temperature trend using line plot
- Calculate variance for statistical analysis

## Tools & Libraries
- Python
- Pandas
- Matplotlib

## Dataset
The dataset contains:
- Hour: Hour of the day (0–23)
- Temperature: Temperature in degree Celsius

## Analysis Performed
- Mean temperature calculation
- Variance calculation
- Line plot for hourly temperature variation

## Conclusion
The temperature varies throughout the day, with higher values during afternoon hours
and lower values during early morning and night.
